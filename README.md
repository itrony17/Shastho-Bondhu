# 🩺 স্বাস্থ্যবন্ধু AI (Shasthobondhu AI)

**স্বাস্থ্যবন্ধু AI** একটি ১০০% ফ্রি, **API Key মুক্ত (Keyless)**, অফলাইন-প্রস্তুত এবং মোবাইল-ফ্রেন্ডলি স্মার্ট স্বাস্থ্য সহকারী ড্যাশবোর্ড। এটি বাংলাদেশের সাধারণ মানুষ, রোগী এবং পরিবারের সদস্যদের জন্য সহজ বাংলায় হাতে লেখা প্রেসক্রিপশন বিশ্লেষণ, ওষুধের রিমাইন্ডার অ্যালার্ম, ব্যক্তিগত মাল্টি-ডিজিজ ডায়েট চার্ট (বাংলা PDF সহ), এবং দেশের ৬৪ জেলার সরকারি ও মেডিকেল কলেজ হাসপাতালের তথ্য প্রদান করে।

## ✨ মূল বৈশিষ্ট্যসমূহ (Key Features)

### ১. 📄 ৩-ব্যান্ড জুমড প্রেসক্রিপশন স্ক্যানার (No API Key Required)
* **হাতে লেখা প্রেসক্রিপশন রিডার:** প্রেসক্রিপশনের ছবি আপলোড করলে ৩-ব্যান্ড জুমড OCR (`Top`, `Middle`, `Bottom`) প্রযুক্তির মাধ্যমে ডাক্তারের নাম, ডিগ্রি, চেম্বার এবং প্রতিটি ওষুধের আসল ব্র্যান্ড নাম ও ডোজ (`1+0+1`) আলাদাভাবে শনাক্ত করে।
* **২-ধাপ লোকাল AI পাইপলাইন (`Qwen2.5-VL` + `MedGemma`):** কোনো পেইড ক্লাউড API Key ছাড়াই সম্পূর্ণ অফলাইনে ও নিরাপদ প্রাইভেসিতে কাজ করে এবং সহজ বাংলায় প্রতিটি ওষুধের কার্যকারিতা ব্যাখ্যা করে।

### ২. ⏰ স্মার্ট ওষুধ রিমাইন্ডার অ্যালার্ম (`.ics` Calendar Integration)
* প্রেসক্রিপশন থেকে শনাক্ত করা ওষুধগুলোর ডোজ অনুযায়ী স্বয়ংক্রিয়ভাবে দৈনিক খাওয়ার সময়সূচি তৈরি করে।
* ১ থেকে ৩০ দিনের জন্য এক ক্লিকেই **`.ics` ক্যালেন্ডার ফাইল** ডাউনলোড করে অ্যান্ড্রয়েড বা আইফোনের ক্যালেন্ডারে সরাসরি অ্যালার্ম সেট করা যায়।

.ics (iCalendar) ফাইলটি একটি সার্বজনীন ক্যালেন্ডার ফাইল ফরম্যাট, যা Android, iPhone, এবং Windows/Mac-এর বিল্ট-ইন ক্যালেন্ডার অ্যাপে সরাসরি অ্যালার্ম বা রিমাইন্ডার হিসেবে কাজ করে।

এটি যেভাবে কাজ করে (ধাপে ধাপে):

1. কীভাবে সময় নির্ধারণ হয় (reminder_helper.py থেকে):
	• প্রেসক্রিপশনে 1+0+1 থাকলে ফাইলটি স্বয়ংক্রিয়ভাবে সকাল ৮:০০ এবং রাত ৯:০০-এর দুটি ইভেন্ট তৈরি করে।
	• 1+1+1 থাকলে সকাল ৮:০০, দুপুর ২:০০, এবং রাত ৯:০০-এর তিনটি ইভেন্ট তৈরি করে।
	• 0+0+1 থাকলে শুধু রাত ৯:০০-এর ইভেন্ট তৈরি করে।
	• স্লাইডার থেকে আপনি যত দিন (১ থেকে ৩০ দিন) সিলেক্ট করবেন, RRULE:FREQ=DAILY;COUNT=... কমান্ডের মাধ্যমে ঠিক তত দিনের জন্য প্রতিদিন একই সময়ে রিপিট অ্যালার্ম সেট হয়ে যায়।
2. মোবাইল বা কম্পিউটারে ব্যবহারের নিয়ম:
	• Android ফোনে: ব্রাউজার থেকে shasthobondhu_medicine_reminder.ics ফাইলটি ডাউনলোড করে ফাইলটিতে ট্যাপ করলে Google Calendar (বা ফোনের ডিফল্ট Calendar অ্যাপ) ওপেন হবে। সেখানে "Add all" বা "Save" বাটনে চাপলেই সব ওষুধের সময়সূচি ও নোটিফিকেশন অ্যালার্ম ফোনে সেট হয়ে যাবে।
	• iPhone / iPad-এ: Safari ব্রাউজার থেকে ফাইলটি ডাউনলোড করলে সরাসরি Apple Calendar পপ-আপ আসবে; "Add All" ট্যাপ করলেই সব অ্যালার্ম যুক্ত হয়ে যাবে।
	• Windows / Mac কম্পিউটারে: ফাইলটিতে ডাবল-ক্লিক করলে Windows Calendar / Outlook / Apple Calendar-এ সব ওষুধের রিমাইন্ডার সেভ হয়ে যাবে।
3. অ্যালার্ম বাজার সময় কী দেখাবে?
	• নির্ধারিত সময়ে (TRIGGER:-PT0M) ফোনে রিং/নোটিফিকেশন বাজবে এবং স্ক্রিনে ওষুধের নাম (💊 ওষুধ সেবন: Cap. Rivacap 3), ডোজ (1+0+1), এবং খাবার আগে না পরে খেতে হবে তা ভেসে উঠবে।


### ৩. 🥗 মাল্টি-ডিজিজ বাংলাদেশি ডায়েট চার্ট ও বাংলা PDF রিপোর্ট
* **Feet ও Inch উচ্চতা ইনপুট:** ফুট ও ইঞ্চিতে উচ্চতা এবং কেজিতে ওজন দিয়ে স্বয়ংক্রিয়ভাবে **BMI** ও দৈনিক ক্যালরি চাহিদা নির্ণয়।
* **একাধিক রোগের সমন্বিত চার্ট (Multi-Disease Checkboxes):** ডায়াবেটিস, উচ্চ রক্তচাপ (High BP), গ্যাস্ট্রিক/আলসার, কিডনি সমস্যা, ফ্যাটি লিভার/কোলেস্টেরল, থাইরয়েড এবং হৃদরোগ—একসাথে একাধিক রোগ নির্বাচন করে দেশীয় খাবারের সুষম তালিকা ও বর্জনীয় খাবারের নির্দেশিকা তৈরি।
* **Nikosh বাংলা ফন্টে অটো PDF সেভ:** চার্ট তৈরির সাথে সাথেই `font/` ফোল্ডারের **Nikosh** ইউনিকোড ফন্ট ব্যবহার করে পরিচ্ছন্ন বাংলা PDF তৈরি হয়, যা স্বয়ংক্রিয়ভাবে `report/` ফোল্ডারে সেভ হয় এবং ব্রাউজার থেকে ডাউনলোড করা যায়।

### ৪. 🏥 বাংলাদেশের ৬৪ জেলার হাসপাতাল ফাইন্ডার ও Google Maps
* বাংলাদেশের ৮টি বিভাগ ও ৬৪ জেলার প্রধান সরকারি হাসপাতাল, সদর হাসপাতাল এবং মেডিকেল কলেজ হাসপাতালের ঠিকানা ও জরুরি যোগাযোগ নম্বর।
* সরাসরি জেলা বা হাসপাতালের নাম লিখে সার্চ করার সুবিধা এবং এক ক্লিকে **Google Maps**-এ লোকেশন দেখার বাটন।

## 🚀 ইনস্টলেশন ও চালানোর নিয়ম (Installation & Setup)

### পূর্বশর্ত (Prerequisites)
* কম্পিউটারে **Python 3.10+** ইনস্টল থাকতে হবে।
* প্রেসক্রিপশন স্ক্যানারের জন্য লোকাল পিসিতে [Ollama](https://ollama.com) ইনস্টল করে নিচের মডেলগুলো পুল করুন:
  ```bash
  ollama pull qwen2.5vl:3b
  ollama pull alibayram/medgemma
  ```

### ধাপ ১: রিপোজিটরি ক্লোন ও প্যাকেজ ইনস্টল
```bash
git clone https://github.com
cd Shasthobondhu-AI

# ভার্চুয়াল এনভায়রনমেন্ট তৈরি ও অ্যাক্টিভেট (Windows)
python -m venv venv
venv\Scripts\activate

# প্রয়োজনীয় লাইব্রেরি ইনস্টল
pip install -r requirements.txt
```

### ধাপ ২: অ্যাপ চালু করুন
```bash
streamlit run app.py
```
ব্রাউজারে **`http://localhost:8501`** ওপেন করলেই অ্যাপটি ব্যবহার করতে পারবেন।

## 📱 মোবাইল থেকে ব্যবহারের নিয়ম
একই Wi-Fi নেটওয়ার্কে থাকা অবস্থায় পিসিতে অ্যাপটি চালু করলে টার্মিনালে একটি **Network URL** (যেমন: `http://192.168.0.105:8501`) দেখা যাবে। মোবাইলের ব্রাউজারে এই লিংকটি ওপেন করলে সরাসরি মোবাইল অ্যাপের মতো ব্যবহার করা যাবে।
